# 实时竞拍大师 — 开发日报

**日期**: 2026-06-03

## 今日完成

### 架构重构：商品中心 → 直播间中心

- 数据库与后端改为以商家为单位的直播间模式，一个商家一个直播间，商品按序拍卖
- WebSocket 房间从单个商品改为商家直播间，同一房间内商品切换无需跳转
- 新增直播间列表接口，前端首页改为直播间卡片网格
- 出价面板嵌入聊天区侧边栏，不再遮挡直播画面

### 前端直播间改版

- 直播间内展示该商家全部商品序列，区分等待中/进行中/已结束状态
- 已结束商品显示成交价和是否中标
- 管理后台新增商家身份切换、场次分组、排序管理功能

### Bug 修复与功能优化

- 修复出价加价幅度异常锁定为 0 的关键 Bug
- 参与人数统计改为独立竞价者计数（原为出价次数累加）
- 移除即将结束自动延时机制，简化竞拍逻辑
- 全端价格显示统一为整数
- 调整测试机器人出价频率，适配演示场景
